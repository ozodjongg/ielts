# SAT Math IELTS bank

8,000 original SAT-style English-language math questions, generated as 80 topics × 100 equivalent variants.

- `questions.csv`: private server bank including canonical answer and explanation.
- `questions_public.csv`: answer-free bank useful for inspection only; production API still serves one question at a time.
- `topics.csv`: topic metadata.
- `QA.json`: generation QA summary.

This is original practice content and is **not official College Board material**.
